# Краснолесье · Cinematic Experience V3

Семисекундное приглашение в Виштынецкий экомузей. Статический сайт, без сборки и production-зависимостей.

## Сценарий
- 0–2 с: пробуждение Роминтской пущи.
- 2–4,5 с: название «Краснолесье».
- 4,5–7 с: приглашение в Виштынецкий экомузей.
- Через 7 с: `location.replace("https://vishtynets.ru/")`.

Ссылка «Перейти сейчас» доступна сразу. Кнопка паузы останавливает и анимацию, и таймер. В `prefers-reduced-motion` показана статичная финальная композиция; таймер можно приостановить. Без JS работает ссылка и семисекундный meta refresh. Звука, аналитики и внешних шрифтов нет.

## Визуальная система
Авторская SVG-иллюстрация леса (не документальная фотография местности), три плана деревьев, независимый ближний план, туман и свет. Анимируются transform и opacity. Системная антиква, тёплый белый, лесной зелёный и приглушённое золото. Иллюстрация создана для проекта, сторонние графические лицензии не требуются.

## Локальный запуск и QA
1. `python -m http.server 8765 --bind 127.0.0.1`
2. Открыть http://127.0.0.1:8765/.
3. Для тестов: `npm install`, затем `npm test` (установленный Microsoft Edge).
4. При отсутствии Edge: `npx playwright install chromium`, затем установить переменную `QA_BROWSER=chromium` перед тестом.

Тесты перехватывают переход на музей и не загружают его страницы. Скриншоты сохраняются в `outputs/`. Для воспроизводимых кадров тест приостанавливает таймер и устанавливает время CSS-анимаций через Web Animations API. В production нет режима обхода перехода.

## Публикация
Сохранить существующий CNAME. После ревью слить PR в main и дождаться успешного GitHub Pages deployment. Проверить HTML, HTTPS и сертификат на каждом домене. GitHub Pages отдаёт HTML с Cache-Control: max-age=600: учитывать до 10 минут кеширования. Имя SVG версионировано; при смене графики менять версию пути.

DNS, настройки Pages и секреты этим изменением не редактируются. Основной сайт vishtynets.ru не изменяется. Подробности: [аудит](docs/AUDIT.md), [проверки](docs/QA.md).
