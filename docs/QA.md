# Проверки V3

Локальный HTTP-сервер, Microsoft Edge / Playwright 1.64.0, Windows. 9 октября 2026.

- Три фазы (1,1 / 3,3 / 5,8 с) проверены на 1440×900, 390×844, 320×568, 844×390. Сохранено 12 скриншотов.
- Ошибок JavaScript нет; горизонтального переполнения нет на всех четырёх размерах.
- Ссылка видима с первого кадра; нажатие открывает https://vishtynets.ru/.
- Tab: ссылка → кнопка паузы; Enter останавливает таймер дольше 7 с; повторное нажатие возобновляет переход.
- Автоматический переход: 7034 мс от начала локального запроса; reduced motion: 7032 мс; JavaScript disabled: 7063 мс. Измеряется запрос перехода, а не загрузка внешнего сайта; внешняя навигация перехвачена тестом.
- Reduced motion: 0 активных анимаций, статичное приглашение, отдельный скриншот.
- Мобильная эмуляция 390×844, DPR 2, CPU slowdown 4×: CLS 0; 198 кадров за около 6,2 с, 3 интервала более 50 мс, максимальный 155,8 мс. Это стресс-проверка на локальном компьютере, не гарантия 60 fps на физическом телефоне.

Ограничения: Safari/Firefox и физические устройства не проверены. Финальная производительность зависит от устройства. Скриншоты фаз сделаны с тестовой паузой; поэтому внизу отображается «Переход приостановлен». Продакшен по умолчанию переходит автоматически.

В репозитории tests/qa.cjs содержит воспроизводимые проверки. В итоговых артефактах сохранены скриншоты, qa-results.json и performance.json.
